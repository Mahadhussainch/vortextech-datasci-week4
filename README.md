# Vortex Tech Capstone: Customer Churn Analysis

## Overview
This repository contains the final capstone project for Week 4 of the Vortex Tech Data Science & Analytics Internship track. The project analyzes an IT customer churn dataset to identify the primary drivers of customer cancellation and provides actionable business recommendations to improve retention.

## Files Included
*   `vortextech_capstone.ipynb`: The full Jupyter Notebook containing the analysis, visualizations, and code appendix.
*   `vortextech_capstone.pdf`: A clean PDF export of the notebook for non-technical stakeholders.
*   `IT_customer_churn.csv`: The raw dataset used for this analysis.

## How to Run
1. Clone this repository to your local machine.
2. Ensure you have Python installed along with `pandas`, `matplotlib`, and `seaborn`.
3. Open `vortextech_capstone.ipynb` in Jupyter Notebook or JupyterLab.
4. Run all cells to reproduce the data cleaning, visualizations, and findings. 

## Key Technologies Used
*   Python (Pandas)
*   Data Visualization (Matplotlib, Seaborn)
